# Antička filozofija

Projekat prevođenja antičke filozofije sa starogrčkog na staroslovenski i srpski jezik.

## Razvoj

```bash
npm run dev
```

Provere i produkcioni build:

```bash
npm run typecheck
npm run build:data
npm run build
npm start
```
